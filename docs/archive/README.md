Related historical material remains at its existing location when other files
reference it: [dated operations](../operations/README.md), [evidence bundles](../evidence/README.md),
and the [earlier build/ship record](../build-ship/README.md).

Name new handoffs `YYYY-MM-DD-topic.md`. Include the source revision, decisions,
changed paths, checks, and unresolved work. Historical observations stay tied to
their original date and environment. Link a newer guide when one supersedes a
record; do not silently rewrite old receipts or move files bound by checksums.
