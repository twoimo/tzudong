# 초기 로딩 스켈레톤을 한 번만 보여 주기

## 목표

쯔동여지도를 처음 열 때 같은 스켈레톤이 사라졌다가 다시 나타나지 않게 한다.

## 사용자

맛집 지도를 처음 여는 방문자.

## 핵심 여정

홈을 열면 인기 검색 맛집과 최근 추가된 맛집 스켈레톤이 한 번만 보이다가 목록으로 바뀐다. 도장, 인사이트 화면도 같은 로딩 껍데기를 반복하지 않는다.

## 범위

- 홈 지도 본문이 데스크톱 오버레이 준비 중에 다시 마운트되지 않게 한다.
- 도장 라우트 로딩 경계는 전체 페이지 스켈레톤을 그리지 않는다.
- 인사이트는 인증 확인과 데이터 조회 사이에 스켈레톤이 끊기지 않게 한다.

## 제외

- 맛집 검수 승인, 프로덕션 데이터 변경, 쓰기 잠금 해제는 이 작업이 아니다.
- 모바일 스토어 제출은 해당 없다.

## 수용 기준

- 데스크톱 홈 초기 로딩에서 `인기 검색 맛집 로딩 중`과 `최근 추가된 맛집 로딩 중`은 각각 한 번만 나타났다 사라진다.
- `/stamp` 초기 로딩에서 `도장 페이지를 불러오는 중`이 두 번 나오지 않는다.
- 관련 소스 계약 테스트가 통과한다.
