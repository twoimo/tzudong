# 외부 화면 검수와 반영

2026-09-20. native subagent 경로 `chatgpt-web/extra-high`, reasoning `xhigh`로 요청했다. agent `01a0be44-08bf-78c2-b996-865906ac2e3a`가 첨부된 데스크톱·모바일 생성 화면 2장을 기준으로 응답했다. 소스·런타임 검수가 아닌 스크린샷 검수이며, 모델 내부 버전명은 별도로 확인하지 않았다. 이 단계 요청 1회. 완료 후 에이전트를 닫았다.

## 응답

> 첨부된 두 스크린샷만 기준으로 보면, 큰 혼란은 줄었지만 3건은 남아 있습니다.
>
> - 중간 — 상단의 프로젝트 선택값 `새 프로젝트`, 빨간 `새 프로젝트` 버튼, 하단 `프로젝트 만들기`가 동시에 보여 신규 생성 동작이 3곳으로 보입니다. 각각의 역할을 즉시 구분하기 어렵습니다.
> - 중간 — 모바일에서 하단 고정 내비게이션이 공급자 카드 위를 덮는 형태입니다. 화면 하단의 `텍스트 모델` 이후 입력 영역이 내비게이션과 너무 가까워 마지막 필드·버튼 접근성이 떨어질 가능성이 보입니다.
> - 낮음 — `외부 AI 사용 허용` 설명이 “웹 직접 열기/결과 가져오기/공식 API 미지원”을 한 영역에 담아, 체크했을 때 실제로 무엇이 달라지는지 빠르게 이해하기 어렵습니다.

## 대응

- 생성 화면에서는 상단 새 프로젝트 버튼을 숨기고 드롭다운 빈 항목을 `저장된 프로젝트 선택`으로 명확히 했다. 기존 프로젝트에서는 새 프로젝트 진입 버튼을 유지한다.
- 외부 AI 체크박스 설명을 켰을 때 선택 가능한 공급자와 직접 결과 가져오기로 줄였다. 공식 API는 공급자 선택의 비활성 항목에서 안내한다. 동의 정책은 그대로다.
- 모바일 하단 가림 가능성은 정지 화면만으로 결함을 확정하지 않고 실제 스크롤·키보드 접근으로 별도 확인한다.

모바일 390×844에서 마지막 이미지 모델 입력 → Tab으로 생성 버튼 포커스를 확인했다. 버튼 하단 y=694.5, 고정 메뉴 상단 y=783.46으로 약 89px 여유가 있으며 중앙 hit-test는 버튼 자체를 반환했다. 가로 넘침은 0px였다. 해당 지적은 실제 접근 차단으로 재현되지 않아 불필요한 CSS 변경을 하지 않았다. [상단](storyboard-create-review-mobile.png) · [마지막 입력과 버튼](storyboard-create-review-mobile-bottom.png).
