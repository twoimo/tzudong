# 전체 UI·Gemini·수집 단계: 구현과 검증 현황

확장된 활성 목표를 수행 중이다. 이번 변경을 완료나 운영 배포로 표시하지 않는다. 사용자가 운영 DB 변경·배포를 허용했으며, 보호된 develop → data → main 순서와 배포 SHA·URL readback을 진행한다.

## 구현

Tremor의 데이터/표 구성과 shadcn의 접근 가능한 제어를 참고하여 공통 토큰·카드·표·입력·탭·모달, 관리자 메뉴/작업 헤더, 공개 서비스 헤더와 로그인 브랜딩을 바꿨다. 로그인 불꽃 이모티콘은 기존 프로젝트 로고로 교체했다. 짧은 스크롤 효과는 선택한 패널에만 한 번 적용하고, 대기 대상을 40개로 제한하며 reduced motion과 키보드 접근을 보존한다.

스토리보드의 운영 진입점은 Gemini 3.8 Flash와 Nano Banana 2/Pro만 실행한다. 이전 공급자 UI는 운영 import에서 분리하고, 이전 생성 API는 관리자 인증 후 410을 반환한다. 이전 문서·이미지·복원 형식과 읽기 경로는 보존한다. SDK는 1회 시도와 명시적 시간제한을 사용하며 불확실한 저장은 확인 없이 재전송하지 않는다. 새 SQL은 기존 마이그레이션을 수정하지 않는다.

OCR는 서버 전용 GEMINI_CREDITS_API_KEY가 있으면 해당 키 하나만 선택한다. 공개 키를 서버 비밀의 대안으로 사용하지 않는다. 기존 OCR 모델·정규화·캐시·일일 제한을 유지하면서 중복 모델 후보를 합치고 취소·전체 시간제한을 처리한다.

메타데이터 날짜 캐시는 성공하지 않은 조회도 완료로 표시하던 오류를 고쳤다. 저장된 결과 해시, 코드·처리 설정과 날짜를 확인하고 채널 작성자를 직렬화한다. 손상된 마지막 줄을 복구할 때 기존 기록과 recollect_id 순서를 보존한다.

## 검증과 남은 작업

- 정식 웹 검사: 2,647 통과·9 건너뜀·실패 0. 변경 후 native/compat TypeScript parity는 2,542개 논리 입력에서 진단 0. 최근 읽기 전용 기록 UI의 native 타입 검사는 통과했고 렌더 확인은 남아 있다.
- 메타데이터 실패·손상·동시 작성/썸네일 경계: 12개 통과. 잘못된 UTF-8을 무시해 완료로 재사용하는 경우도 차단했다. 실제 원본 1,127개가 검증 형식에 부합한다.
- 저장·임대·동시 claim·CAS·복원·브라우저 역할 거부: 격리 PostgreSQL 17.6에서 13개 통과. Supabase의 전체 확장/Storage 운영 환경을 재현했다는 뜻은 아니다.

- 데스크톱·모바일 실제 렌더 일부를 확인했다. 일부 초기 캡처는 로딩/빈 프레임/뷰포트 불일치여서 통과 증빙에서 제외한다. 전체 공개 페이지·모바일/태블릿·dark/reduced-motion 매트릭스와 채워진 목록/상세 검증을 마무리해야 한다.
- 기존 파이프라인의 cold 변환, 제한된 미디어 처리, admission 지연 회귀와 나머지 한계는 pipeline-performance-20261002.md에 그대로 보존했다. 전체 파이프라인의 5조건/7쌍 비교와 변경 전 브라우저 100회 측정, 소비 단계 전체 미디어 공유, 원격 호스트/TPM/RPD 검증은 남아 있다.
- 운영 SQL은 아래 이력으로 적용 및 권한 readback을 마쳤다. 보호 PR 승격·배포·배포된 OCR/스토리보드 워커 readback은 남아 있다. 사용자가 승인한 범위 내에서 계속 수행한다.
- 카드 삭제는 이전 공식 화면에서 유효한 대체 수단을 요구해 완료하지 못했다. 계정 폐쇄나 결제 해제를 대안으로 실행하지 않았다. 이 상태는 새 삭제 영수증이 아니다.

초안 PR #3099에서 npm 취약점 검사는 웹 9건(높음 8·치명적 1), 백엔드 높음 1건을 보고했다.
