- 맛집 검수는 최신 사용자 지시인 “승인까지 자동 운영해”를 적용한다. 자동 승인 정책·실행 상한·변경 감지·관리자 수정 보호·보류 사유·실행 이력과 중지 기능을 포함한다. 평가 근거 누락, 중복, 좌표 충돌은 승인하지 않고 재검수 또는 보류한다.
