이 문서는 기존 활성 목표 `01a0f860-10d0-71b0-bb2a-95c2b52e025e`에 추가된 사용자 요청의 실행 범위다. 목표 API는 상태 변경만 지원한다. 기존 목표를 완료하거나 대체했다는 증거로 사용하지 않는다.

## 승인 범위

- 격리 후보에서 구현·회귀 검증·재현 가능한 측정·운영 적용안까지 수행한다. 사용자가 활성 목표에서 운영 DB 변경과 배포를 명시적으로 허용했다. 보호 브랜치의 develop → data → main 순서, 현재 운영 rollback SHA와 배포 후 readback을 지킨다.
- 일회성 10,000원 충전과 기존 프로젝트 결제 연결은 완료했다. 재결제하지 않는다. 자동 충전은 끈 상태를 유지한다.
- 카드 삭제 요청은 보존한다. Google이 유효한 대체 수단을 요구하여 삭제되지 않았다. 결제 계정 폐쇄나 프로젝트 결제 해제를 카드 삭제의 대안으로 실행하지 않는다.
- 스토리보드는 Google Gemini만 허용한다. 사용자 요청의 이미지 모델명은 현재 공식 API 모델과 대조하고, 미확인 모델명을 만들어 호출하지 않는다. OCR의 기존 품질·일일 제한·동의·캐시 계약을 유지한다.
- 맛집 검수는 최신 사용자 지시인 “승인까지 자동 운영해”를 적용한다. 자동 승인 정책·실행 상한·변경 감지·관리자 수정 보호·보류 사유·실행 이력과 중지 기능을 포함한다. 평가 근거 누락, 중복, 좌표 충돌은 승인하지 않고 재검수 또는 보류한다.
