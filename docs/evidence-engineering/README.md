# 근거 엔지니어링 계약

기준일은 2026-10-17이다. 원본 키트는 저장소 밖에 둔다. 이 디렉터리가 이후 세션의 규범 요약이다.

권위 순서는 다음과 같다.

1. ChatGPT 제8장 합의록의 판정과 최종 계약.
2. 서로 충돌하는데 합의록이 한쪽을 고르지 않은 항목은 `contradictions.md`에 열린 모순으로 남긴다.
3. Gemini 감사의 구체적 식별자와 반증.
4. 마스터 플랜 Thesis와 작업지시서 W001–W018.

구현된 순수 계약은 `apps/web/lib/evidence-engineering/`이다. 이 문서는 그 모듈의 규범이고, 아직 없는 추출·질의·DB·UI 작업을 대체하지 않는다.

아키텍처 불변식은 다음 다섯 가지다.

- I01. Node.js 프로세스는 전체 영상 파일을 적재하지 않는다. 키프레임 탐색과 구간 디코딩은 기존 추출 경로의 FFmpeg 경계에서 한다.
- I02. 네이버 지도 마커는 WebGL 컨텍스트를 추가로 만들지 않는다.
- I03. Three.js를 켤 때는 `RestaurantDetailPanel` 안에서 `next/dynamic`으로만 켜고, 마커에는 켜지 않는다. 기본 배지는 정적 WebP다.
- I04. 인기 점수는 요청 경로에서 계산하지 않는다. 일일 배치가 위성 테이블에 쓴다.
- I05. `youtube_link`의 영상 정체성과 프레임의 타임스탬프 시크는 둘 다 유지한다. 시크 URL은 별도 필드다.

개인정보 경계는 `docs/agents/privacy.md`를 따른다. 프레임 페이로드에 원문 OCR, 전화번호, 이메일, 기기 정밀 위치, 쿠키, 세션 토큰, 요청 본문, 제공자 진단문을 넣지 않는다. 상호명과 지점명은 한 줄의 짧은 추출 결과만 허용한다. 사업장 주소와 사업장 좌표는 기기 위치와 다른 계약이다. 보존 기간은 이 계약이 정하지 않는다.
