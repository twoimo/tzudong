# App Review 제출 안내

쯔동여지도 앱 심사 제출 전에 App Store Connect / Google Play Console에 함께 입력할 운영 메모입니다.

## 공개 정책 URL

- 개인정보 처리방침: `https://www.tzudong.app/privacy`
- 데이터 삭제 요청 안내: `https://www.tzudong.app/data-deletion`
- 앱 내 계정 삭제 경로: 로그인 후 `마이페이지 > 프로필/계정 관리 > 계정 완전 삭제`
- 문의 이메일: `cs@tzudong.app`

## iOS App Review 테스트 계정

> 실제 심사 제출 전, 아래 값을 운영자가 생성한 심사용 계정으로 채워야 합니다. 계정은 일반 사용자 권한으로 두고, 리뷰 작성/북마크/마이페이지/계정 삭제 진입이 가능해야 합니다.

- 로그인 방식: 이메일/비밀번호
- 이메일: `<심사용 이메일 입력>`
- 비밀번호: `<심사용 비밀번호 입력>`
- 2단계 인증: 사용하지 않음
- Google 로그인만 필요한 시나리오: 현재 기본 심사용 계정은 이메일/비밀번호 로그인으로 제공

## 심사자 확인 경로

1. 앱 실행 후 홈 화면에서 `로그인`을 누릅니다.
2. 위 테스트 계정으로 로그인합니다.
3. 주요 확인 경로
   - 맛집 지도/목록 확인
   - 맛집 상세와 영상/리뷰 확인
   - 북마크 추가/해제
   - 마이페이지 진입
   - `마이페이지 > 프로필/계정 관리`에서 계정 삭제 진입 확인
4. 계정 완전 삭제는 되돌릴 수 없으므로, 심사 메모에는 “삭제 버튼 진입과 본인확인 입력창까지만 확인해도 됩니다”라고 적습니다.

## 계정 삭제 및 개인정보 처리 설명

- 사용자는 앱 안에서 직접 계정 완전 삭제를 요청할 수 있습니다.
- 계정 삭제 시 이메일/인증 정보, 북마크, 알림, 통계, 권한 정보가 삭제됩니다.
- 작성 리뷰와 제보는 서비스 무결성을 위해 `탈퇴한 사용자`로 익명화되어 남을 수 있습니다.
- 로그인이 불가능한 사용자는 `cs@tzudong.app`로 데이터 삭제를 요청할 수 있습니다.

## 제출 전 체크리스트

- [ ] `/privacy`가 프로덕션에서 200으로 열림
- [ ] `/data-deletion`이 프로덕션에서 200으로 열림
- [ ] 테스트 계정 이메일/비밀번호가 실제로 로그인됨
- [ ] 테스트 계정이 정지/삭제/비밀번호 만료 상태가 아님
- [ ] App Review Notes에 테스트 계정과 주요 확인 경로를 입력함
- [ ] Google Play Console 데이터 보안/계정 삭제 URL에 공개 URL을 입력함
