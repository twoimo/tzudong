적용 내용

  • 통계 영역은 1행 3열을 유지하되 아이콘 칩과 카드 테두리로 가독성을 높임.

  • 도장/리뷰/좋아요 콘텐츠에 섹션 헤더와 개수 배지를 추가.
  • StampCard size="default" stampSize="compact"는 유지해 카드형 도장 회귀를 방지.
