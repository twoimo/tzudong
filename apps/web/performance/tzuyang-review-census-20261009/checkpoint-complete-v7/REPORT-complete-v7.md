# 쯔양 리뷰 전수 검사: 모델 검사 완료, 원문·운영 수정은 별도

동결한 1,659개 레코드를 Gemini 3.8 Flash, HIGH로 전수 검사했다. 190개 유효 응답 체크포인트의 실제 modelVersion, 요청 추론 강도, 입력·프롬프트 해시 및 순서·누락·중복을 검증했다. 빈 리뷰와 삭제된 레코드도 검사 대상에 포함했고, 새 리뷰를 지어내거나 삭제 상태를 복원하지 않았다. 결과는 영상 대조 완료나 모든 문제 수정 완료를 뜻하지 않는다.

모델의 EMPTY_REVIEW 판정 229건은 원문이 실제로 빈 222건과 다르다. 짧거나 정보가 부족한 비어 있지 않은 문장도 이 코드로 분류될 수 있다. 이슈 코드는 서로 겹치므로 합계를 문제가 있는 레코드 수로 사용하지 않는다. 채널이 확인되지 않은 승인 레코드는 쯔양 발언으로 자동 수정하지 않는다.

승인 레코드의 이슈 후보는 문장 완결성 49, 작성자 1인칭 11, 서식 11, 영상 근거 필요 33, 모순 1, 빈/불충분 24, 내부 참조 9, 홍보성 문체 32, 레코드 불일치 29건이었다. 이 수치는 모델 분류이며 독립적으로 확정한 사실 오류 건수가 아니다.

## 구현한 수정

- 공통 표시 함수가 대괄호 ts 참조뿐 아니라 `(ts:623, 781)` 및 `{ts:256, 416-422}` 형태도 제거한다. 일반 영업시간·식사시간·수량 괄호는 보존한다.
- 일반 문단에 그대로 보이던 쌍을 이룬 `**강조**`와 한국어 문장 끝 구두점 앞 불필요한 공백을 정리한다. 실제 비판·가격·수량·원문 문자열·영상 연결은 보존한다. 공개 상세와 공통 함수를 사용하는 관리자 화면에 동일하게 적용된다.
- 단일 영상·청크·최종 병합 생성 프롬프트에 같은 3인칭 존댓말, 직접 인용과 발언자 구분, 부정적 평가·조건·불확실성 보존, 타임스탬프는 reasoning_basis에 기록하는 규칙을 추가했다. 프롬프트 변경만으로 이후 모델 준수율이 입증됐다고 주장하지 않는다.

모델 제안 중 원문과 형식 정리만으로 정확히 동일함을 확인한 승인 tzuyang 레코드는 8건이다. 8건 모두 기존 관리자 수정 표시가 있어 원문·전체 레코드 해시를 묶은 비공개 계획으로 보존했다. 사실 변경·영상 사실 인증·운영 DB 적용은 0건이다. 일반 사용자 리뷰는 변경하지 않았다. 새 발언 귀속을 추가하거나 비판·추천 강도를 바꾸는 나머지 제안은 자동 승인하지 않았다.

## 검증과 남은 작업

표시·병합 단위 검사 12건 통과, 파서 5건 통과, 데이터 계약 19건 통과/1건 건너뜀, 변경 TS 린트 통과. 별도 통합 소스의 전체 3,347건 통과/11건 건너뜀, production build/CSS 및 합성 데이터 브라우저 10건 통과는 해당 통합 SHA에서 얻은 결과다. 이번 표시 함수 변경 이후의 새 production rendering 및 보호된 승격·운영 배포는 아직 별도 재검증 대상이다.

운영 내용 변경은 최신 원본의 ID·상태·채널·updated_at·관리자 잠금·전체 레코드 해시 대조와 기존 Preview → Confirm → Apply → Readback → Audit 경로를 거쳐야 한다. 사실 또는 레코드 불일치는 원 영상·자막과 대조하기 전 수정하지 않는다. 빈 리뷰는 생성 근거가 확보되기 전 채우지 않는다.

기존 60요청 batch는 완료 응답 60개를 모두 거부했고 유효 검사 0건이었다. 실패 응답의 토큰 메타데이터 2,603,453개와 앞선 streaming 실패를 보존한다. 성공 체크포인트 토큰 메타데이터는 census-complete-v7.json에 별도로 집계했다. 실제 청구 금액은 확인되지 않았으며 처리 성공이나 batch 사용을 비용 절감으로 보고하지 않는다.

## 재현

입력 원문·모델 제안은 700/600 권한의 비공개 runtime에만 있다. 공개 증거에는 키·상태·이슈·텍스트 해시만 포함한다. 인증정보, 개인 계정 식별자, 원문 리뷰/공급자 응답 본문은 저장하지 않는다.

`aggregate_census_v7.py --private-root <승인된 비공개 원본 디렉터리> --output <새 결과 파일> --private-plan <새 비공개 계획 파일>`로 동결 입력 SHA와 모델/프롬프트 결속, 전체 1,659개 키, 누락·중복 거부 및 집계를 재실행한다. 생성 파일을 덮어쓰지 않는다. 외부 감사자는 공개 상태·해시·개수·체크포인트 결속을 확인할 수 있고, 의미/영상 검증에는 별도 승인된 원문 접근이 필요하다.
