**그대로 되살리면 안 되는 원본 의도**

현재 dashboard route 테스트는 자유로운 `error.name`을 읽지 않고 고정 코드만 기록하도록 요구하며, 잘못된 ID에는 로그가 없어야 한다. 원본 진단 분류/invalid-shape·length 로그와 이 차이를 구분했다. 또한 원본 WeakMap은 배열 identity만으로 bucket을 저장하고 같은 bucket을 반환하므로, 현재의 in-place 배열·링크 변경과 결과 배열 독립성 테스트를 만족하지 못한다. 이 성능 의도는 미충족이지만 원본 그대로의 이식은 해결책이 아니다. 안전한 대체 구현 또는 명시적인 의도 제외 기록이 필요하다.

**측정 자료의 경계**

원본 세 benchmark는 지역 fixture/함수 수준 microbenchmark이다. 원본 예산은 absolute 16 ms, relative 최소 1.3, combined MAD/median 최대 0.15이며, 이번 작업에서 실행하거나 유효성을 재검증하지 않았다. 영상 lookup warm 결과는 timer floor이고 cold 생성 비용과 다르며, 지도 lookup 원본 결과는 noise 예산 초과로 accepted=false이다. updated-at 스크립트는 독립 JS 함수 비교라 main 직접 실행 결과도 아니다. 원본의 accepted=true나 수치를 현재 UI·실제 SDK·hosted 성과로 재사용하지 않는다. 현재 성능 향상 주장은 0건이다.

**의도별 semantic table**

“충족/동등”은 소스와 기존 테스트의 정적 대조 결과이며 테스트 실행 성공을 뜻하지 않는다. test/doc/evidence는 구현과 별도 행으로 기록했다. #3032 patch에는 doc/evidence 산출물 자체가 없다.
