# 관리자 KPI 및 공통 레이아웃 검증

로컬 격리 후보에서 관리자 15개 메뉴를 데스크톱·모바일로 확인했습니다. 공통 여백은 16/12px, 제목은 16px, 일반 버튼은 12px, KPI 도구 버튼은 11px입니다. 전체 30개 관측에서 캔버스 가로 넘침이 없었습니다.

KPI는 실제 YouTube에서 수집해 로컬 DB에 독립적으로 readback한 490개 영상과 채널 통계를 사용합니다. 월별 그래프는 업로드 월 집단의 영상당 평균이며, 과거 월별 트래픽을 뜻하지 않습니다. 비교 이력이 없는 기간은 누적 통계와 비교 대기를 표시합니다. 30분 비교, 모든 표 전환, 50행 페이지 이동과 마지막 40행, 키보드 툴팁을 실제 브라우저에서 확인했습니다. 요청한 상시 수집 배너는 제거됐습니다.

## 성능 측정 범위

동일한 합성 490행을 사용한 로컬 SSR 첫 페이지 측정입니다. 준비 5회, 교차 순서 30쌍의 최종 측정에서 p75는 30.912ms → 3.819ms(27.093ms, 87.6% 감소), 렌더링 행 수는 490 → 50입니다. 전체 490개는 페이지 이동으로 접근할 수 있습니다.

절대 예산: 후보 p75 50ms 이하. 상대 예산: 기준의 80% 이하. 노이즈 예산: 개선폭이 max(1ms, 기준/후보 MAD의 2배) 이상. MAD는 기준 1.779ms, 후보 0.364ms입니다. 이 한정된 로컬 비교는 통과했으나 브라우저 전체 지연·운영 환경 성능·세계 최고 수준을 증명하지 않습니다. canonical G003 채택 슬라이스는 0입니다.

독립 DB 읽기 병렬화의 별도 합성 지연 측정은 ../youtube-kpi-read-scheduling-20260908/에 있습니다. 그 결과를 운영 네트워크 속도나 이 SSR 개선에 합산하지 않습니다.

검증: 관련 단위·소스 테스트 75개 통과, 대상 ESLint 통과, 프로젝트의 지정된 두 컴파일러 parity 통과. 운영 배포 또는 법적 승인에 관한 증거는 아닙니다.

원시 측정, 점수, 고정 소스, 화면 읽기 기록의 해시는 artifact-map.json에 있습니다. 그 파일 자체의 SHA-256은 작업 응답 및 별도 /tmp/tzudong-kpi-artifact-map.sha256에 기록합니다.
