최종 운영1ab5 소스의 추가 실기기 자연 JS heap 반복 관찰용 후속 packet이다. 기존 frozen2183개 증거와 map/pin을 변경하지 않는다. 현재0표본이며 기기 인증 잠금 해제가 필요하다. Samsung A1 B1 B2 A2, Chrome A1 B1 순서로 각각60회 시행하고 개별 쌍·전체집계·endpoint·peak를 모두 공개한다. Browser 전체RSS/GPU 또는 누수 없음의 증명으로 해석하지 않는다. 기존 user 탭·auth·설정·forward/reverse를 보존한다.

후속 실행은 `python3 run-native-seeded-sequence-v1.py <새-label>`이다. 여섯 run이 모두 완료된 후 `python3 aggregate-native-sequence.py <동일-label>`로 집계한다.
